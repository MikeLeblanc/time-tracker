# Time Tracker

A simple GO/STOP time tracker with projects. It runs in the browser and installs as an app.

## Install (one click)

1. Open the app's web address in Chrome or Edge.
2. Click **Install app** at the top right (or the install icon in the address bar).

It then opens from the Start menu / desktop like any app, and works offline.

## Updates

Automatic: publish new files to the hosting site and the app picks them up the next time it is opened.

## Data

Time entries are stored on the computer where the app is installed. Use **Save backup file** regularly,
and **Export to Excel (CSV)** for billing.
